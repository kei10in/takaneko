# Update Publications

## 配信 URL

配信の URL を設定する場合は、それぞれ下記から探すと良いです。

- Apple Music: AppleのiTunes Search APIで楽曲検索し、曲別URLを取得。
- Spotify: TuneCore (linkco.re) やLinkfire (jvcmusic.lnk.to) からたどり、Spotifyの曲一覧で確認。
- YouTube Music: 配信まとめページから公式配信アルバムをたどり、曲別URLを取得。検索も使って歌唱アーティストを照合。
- ISRC: Deezerの公開APIで確認。
